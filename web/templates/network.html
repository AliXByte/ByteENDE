{{ icon('device') }} Device (MAC address) access

Honest limitation, read before enabling: a MAC address is only visible between devices on the same local network. ByteENDE can match it (Linux hosts only, via the system ARP table) for a device on your LAN, but it can never see the MAC address of a client connecting over the internet or through a router — for remote access control, use the IP rules above instead. When this is on, any request that isn't one of your local network's allowed MACs is denied.
