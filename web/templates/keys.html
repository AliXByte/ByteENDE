{{ icon('bolt') }} How to call the API

Send the token as a Bearer header. Every call must match the key's scope and stay under its per-minute limit, or you'll get a 403 / 429.
curl -X POST {{ request.host_url }}api/v1/codec \ -H "Authorization: Bearer <TOKEN>" \ -H "Content-Type: application/json" \ -d '{"codec":"base64","mode":"encode","text":"hello"}'
