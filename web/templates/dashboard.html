{{ icon('hash') }} Hash generator

Produces a one-way fingerprint of your text with MD5, SHA-1, SHA-256 and SHA-512 at once. Hashing cannot be reversed — use it to verify integrity or compare values, not to "decode" anything.

{{ icon('jwt') }} JWT

Inspect a JSON Web Token's header and payload (no secret needed), or build and sign a new one with HS256/384/512.
Decoding only reads the header and payload — it does not check the signature. Use the API's /jwt/verify if you need that.

{{ icon('lock') }} AES-256-GCM encryption

Authenticated encryption: your password is run through PBKDF2 (200,000 rounds) to derive a key, so a tampered or wrong-password ciphertext fails to decrypt instead of silently returning garbage. The result is a single portable Base64 blob — keep the password safe, it is never stored.
